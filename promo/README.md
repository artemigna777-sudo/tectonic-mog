# Реклама GeoBot для TikTok

Вертикальные ролики 1080×1920 в формате роликов «Курьера ПДД» (репозиторий pdd.game, `trailer/ads`, `engine4.ts`):
диалог светящихся человечков на чёрном → вспышка → история на гравюрах, нарисованных кодом → вывод из двух строк
→ «Бот в био». Движок (`engine3.ts`, `engine4.ts`, `draw.ts`, `etch.ts`), зерно, шрифт Montserrat (SIL OFL)
и GSAP скопированы оттуда; добавлен только свой текст последней карточки (`bioText`).

## «Живые» ролики (`engine6.ts`, с 02)

По образцам IQuit (лифт, спальня, библиотека): ночная сцена с обстановкой и светом, человечки двигаются (руки
через две вложенные группы — плечо и локоть, голова, моргание, свет телефона на лице), монтаж «через плечо» с
размытым силуэтом, цитата сверху всю реплику, инфографика поверх затемнённой сцены, бот крупно в телефоне в
руках, финал и карточка «GeoSleuth в Telegram». ~36 секунд.

```
sh ads/snap6.sh 02-koordinaty     # снимки кадров
sh ads/render6.sh 02-koordinaty   # → ads/mp4/geobot-ad-02-koordinaty.mp4 и копия без звука
```

Музыка — `ads/music/<id>.wav`, если положить (в репозиторий не кладём); иначе ролик немой.

Музыка ролика 03 — из образца «принцесса на горошине» (136 BPM), первые 25 с:
`ffmpeg -i <образец>.mp4 -t 25 -vn -af "afade=t=out:st=24.6:d=0.4" -ar 44100 -ac 2 promo/ads/music/03-zolushka.wav`
(тихое вступление — диалог, дроп 7,9 с — сказка, затишье 21,3 с — вывод).

Музыка ролика 02 — из образцов IQuit (во всех трёх один и тот же трек, ~112 BPM), первые 41,4 с:
`ffmpeg -i <образец>.mp4 -t 41.4 -vn -af "afade=t=out:st=41.0:d=0.4" -ar 44100 -ac 2 promo/ads/music/02-koordinaty.wav`.
Конец ролика уложен на трек: затишье 30,25 с — ночь и часы «23:59 → 05:30», удар дропа 34,03 с — суббота у
церкви, вспышка фото 35,67 с, акцент 37,27 с — «GeoSleuth в Telegram». Громкость выравнивается до −14 LUFS.

## Как собрать

Нужны Node.js 22 и ffmpeg.

```
cd promo && npm install
sh ads/snap.sh 01-polinezija      # снимки кадров → ads/out/01-polinezija/snapshots/
sh ads/render.sh 01-polinezija    # → ads/mp4/geobot-ad-01-polinezija.mp4 и копия без звука
```

Музыка: положите `ads/music/plan.wav` (тот же трек, что у роликов 31–32 «Курьера ПДД», в репозиторий не кладём).
Без неё ролик собирается немым — звук удобнее выбрать прямо в TikTok.
