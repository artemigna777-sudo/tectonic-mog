# Реклама GeoBot для TikTok

Вертикальные ролики 1080×1920 в формате роликов «Курьера ПДД» (репозиторий pdd.game, `trailer/ads`, `engine4.ts`):
диалог светящихся человечков на чёрном → вспышка → история на гравюрах, нарисованных кодом → вывод из двух строк
→ «Бот в био». Движок (`engine3.ts`, `engine4.ts`, `draw.ts`, `etch.ts`), зерно, шрифт Montserrat (SIL OFL)
и GSAP скопированы оттуда; добавлен только свой текст последней карточки (`bioText`).

## Как собрать

Нужны Node.js 22 и ffmpeg.

```
cd promo && npm install
sh ads/snap.sh 01-polinezija      # снимки кадров → ads/out/01-polinezija/snapshots/
sh ads/render.sh 01-polinezija    # → ads/mp4/geobot-ad-01-polinezija.mp4 и копия без звука
```

Музыка: положите `ads/music/plan.wav` (тот же трек, что у роликов 31–32 «Курьера ПДД», в репозиторий не кладём).
Без неё ролик собирается немым — звук удобнее выбрать прямо в TikTok.
