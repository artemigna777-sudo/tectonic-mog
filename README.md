# Земля трясётся 🤲 67

Сайт-тест в виде игры про **геологические чрезвычайные ситуации**: землетрясения, вулканы, оползни, обвалы, сели, карст, сейсмоопасные районы России и правила поведения.

- 67 вопросов с 4 вариантами ответа; вопросы и ответы перемешиваются каждую игру.
- Прогресс в виде сейсмограммы: на ошибке — всплеск, тряска экрана и трещина по карточке.
- Комбо-серия с множителем очков 🔥 x2…x5, конфетти из 🪨💎🌋.
- Звания от «Sub5 по геологии 🪨» до «True Adam литосферы 👑», лучший результат сохраняется в браузере.
- Звуки на Web Audio API (можно выключить), управление с клавиатуры: `1–4` — ответ, `Enter` — дальше.
- Чистый HTML + CSS + JS, без сборки и зависимостей: `index.html`, `style.css`, `app.js`, `questions.js`.

## Как опубликовать на GitHub Pages

1. Создай пустой репозиторий на GitHub.
2. В папке проекта:
   ```bash
   git remote add origin <ссылка на репозиторий>
   git branch -M main
   git push -u origin main
   ```
3. В репозитории: **Settings → Pages → Source: Deploy from branch → `main` / `(root)`** → Save.
4. Через 1–2 минуты сайт будет по адресу `https://<ник>.github.io/<репозиторий>/`.

Локально можно просто открыть `index.html` в браузере.
