# GeoBot — бот, который ищет, где снято фото

Пришлите боту фото, и он:

1. **Прочитает метаданные.** Если фото отправлено *файлом*, в нём часто есть GPS, направление камеры и время съёмки. Тогда ответ точный до метров.
2. **Прочитает текст на фото** через OCR.space и проверит его по справочникам:
   - алфавит: татарский, башкирский, казахский, украинский, белорусский и т. д.;
   - телефонные коды городов и стран;
   - коды регионов на номерах машин;
   - домены сайтов.
3. **Найдёт адрес или название** из текста на карте OpenStreetMap, внутри страны и города, на которые указывают остальные подсказки.
4. **Даст кнопки «Яндекс», «Google Lens» и «Bing».** Поиск по картинке откроется у вас в браузере. Фото для этого временно загружается на Litterbox и удаляется через 1 час.
5. **Пришлёт точку на карте** прямо в Telegram и фото с Wikimedia Commons рядом с ней, чтобы было с чем сравнить.
6. **Необязательно:** если указан ключ Gemini API, отправит фото в Gemini, и тот проанализирует архитектуру, растительность, знаки и солнце.
7. **Кнопка «Текст для ИИ-чата»** собирает всё найденное в текст. Его можно вставить вместе с фото в приложение Gemini, ChatGPT или Claude.

Бот работает без ИИ и без платных сервисов. Памяти ему нужно около 80 МБ, поэтому хватает бесплатного тарифа Bot-Hosting.net (256 МБ). Тяжёлые библиотеки вроде aiogram здесь не используются: с Telegram бот общается напрямую через Bot API.

## Что понадобится

| Что | Где взять | Обязательно? |
|---|---|---|
| Токен бота | Telegram → [@BotFather](https://t.me/BotFather) → `/newbot` | да |
| Ключ OCR.space | [ocr.space/ocrapi](https://ocr.space/ocrapi), бесплатный ключ приходит на почту | желательно, без него текст на фото не читается |
| Ключ Gemini API | [aistudio.google.com](https://aistudio.google.com) → *Get API key* | нет |

Ключи и токен **никому не пересылайте**: ни в чат, ни в код, ни на GitHub. Они вписываются только в файл `.env` на сервере.

## Настройка

1. Скопируйте `.env.example` в `.env`.
2. Впишите `BOT_TOKEN` и `OCR_SPACE_KEY`. По желанию впишите `GEMINI_API_KEY`.
3. Запустите бота и напишите ему `/id`. Он ответит вашим Telegram ID.
4. Впишите этот ID в `ALLOWED_USERS` (несколько ID — через запятую) и перезапустите бота.

Пока `ALLOWED_USERS` пустой, бот никого не обслуживает, только сообщает ID. Это защита: в чужих руках определение места по фото может использоваться для слежки.

## Запуск на Bot-Hosting.net

Интерфейс панели может отличаться. Общий порядок такой:

1. Зарегистрируйтесь на [bot-hosting.net](https://bot-hosting.net) и создайте бесплатный сервер с **Python**.
2. Откройте файловый менеджер сервера и загрузите туда **содержимое папки `geobot/`**:
   - файлы `main.py`, `requirements.txt` и `.env`;
   - папку `geobot/` с кодом.
3. В настройках запуска (*Startup*) укажите главный файл `main.py` и файл зависимостей `requirements.txt`.
4. Нажмите **Start** и посмотрите консоль. Должна появиться строка `bot started`.
5. **Каждые 4 дня продлевайте сервер в панели**, иначе бесплатный сервер остановится.

Если при установке ругается на `pillow-heif`, удалите эту строку из `requirements.txt`. Бот будет работать, только без поддержки HEIC-файлов с iPhone. Обычные фото и JPG будут обрабатываться как раньше.

## Запуск на своём компьютере

```bash
cd geobot
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

Нужен Python 3.10 или новее.

## Gemini

- Модель задаётся переменной `GEMINI_MODEL` (по умолчанию `gemini-3.8-flash`). Если бесплатный лимит этой модели слишком маленький, попробуйте более лёгкую, например `gemini-3.1-flash-lite`. Актуальные лимиты видны в Google AI Studio.
- Подписка Gemini Pro к API не относится: у API свой бесплатный лимит.
- Ключ должен принадлежать вам. Пользуясь им, вы соглашаетесь с [условиями Gemini API](https://ai.google.dev/gemini-api/terms).
- Фото отправляется в Google, поэтому не присылайте боту снимки, которые не хотели бы показывать посторонним.

## Ограничения

- **Обычные фото Telegram сжимает и удаляет из них GPS.** Для точности отправляйте файлом: 📎 → Файл.
- **Без надписей и узнаваемых объектов** без Gemini бот даст только кнопки поиска и общие подсказки.
- **Справочник телефонных кодов городов** охватывает только крупные города России. Если кода нет в справочнике, это не значит, что номер не российский.
- **Бесплатные сервисы** (OCR.space, OpenStreetMap, Wikimedia, Litterbox) могут ограничивать частоту запросов. Тогда бот просто пропустит соответствующий шаг.

## Устройство

```
main.py              запуск
geobot/bot.py        приём сообщений и ответы
geobot/telegram.py   минимальный клиент Telegram Bot API
geobot/analyze.py    порядок проверок и выбор лучшей точки
geobot/exif.py       метаданные: GPS, направление, время
geobot/textclues.py  алфавиты, телефоны, номера машин, домены
geobot/services.py   OCR.space, Litterbox, OpenStreetMap, Wikimedia Commons
geobot/gemini.py     необязательный анализ изображения в Gemini
geobot/report.py     текст ответа и «досье» для ИИ-чата
geobot/data/         справочники
```

Тесты: `pip install pytest && python -m pytest tests`.

Таблица телефонных кодов стран взята из проекта [geo-sleuth](https://github.com/Oldcircle/geo-sleuth) (MIT License, © 2026 Oldcircle), данные — Wikipedia.
