# GeoBot — бот, который ищет, где снято фото

Пришлите боту фото, и он:

1. **Прочитает метаданные.** Если фото отправлено *файлом*, в нём часто есть GPS, направление камеры и время съёмки. Тогда ответ точный до метров.
2. **Прочитает текст на фото** через OCR.space и проверит его по справочникам:
   - алфавит: татарский, башкирский, казахский, украинский, белорусский и т. д.;
   - телефонные коды городов и стран;
   - коды регионов на номерах машин;
   - домены сайтов.
3. **Справочники по тексту на фото:**
   - **номера трасс** (М-7, Р-239, старые М-55 и т. п.) дают коридор регионов вдоль дороги;
   - **региональные сети, банки, АЗС, связь** («Бахетле», «Ак Барс», «Татнефть», «Монетка», «Самбери»…);
   - **справочник населённых пунктов России** (177 тысяч, офлайн): прочитанное на фото «Дубровка» превращается в список всех Дубровок, который пересекается с регионами из других улик. Например, номер 116 или вывеска «Татнефть» → Дубровка в Татарстане.
4. **Найдёт адрес или название** из текста на карте OpenStreetMap, внутри страны и города, на которые указывают остальные подсказки.
5. **Сам поищет фото в Яндексе.** Бот загружает снимок в поиск по картинке и читает результаты: теги («церковь казанской иконы»), страницы с похожими фото и текст, который Яндекс распознал на снимке. Название места, которое повторяется на нескольких **разных** сайтах, ищется на карте. Такой ответ засчитывается, только если поиск узнал достопримечательность (храм, памятник, мост и т. п.) и район совпадает с текстом на страницах. Для обычных домов и улиц Яндекс находит просто похожие места, и бот так и пишет.
6. **Даст кнопки «Яндекс», «Google Lens» и «Bing»,** чтобы посмотреть результаты самому. Ссылки ведут на копию фото, которую хранит Яндекс. Если загрузка в Яндекс не удалась, фото временно кладётся на Litterbox и удаляется через 1 час.
7. **Пришлёт точку на карте** прямо в Telegram и фото с Wikimedia Commons рядом с ней, чтобы было с чем сравнить.
8. **Необязательно — Gemini, как игрок GeoGuessr.** Если указан ключ Gemini API:
   - лёгкая модель (Flash-Lite, лимит 500 запросов в день) находит на фото 3–4 детали: знак, столб, фасад, бордюр, растения;
   - бот вырезает их из оригинала в полном разрешении; самые крупные фрагменты дополнительно ищутся в Яндексе;
   - Flash получает фото, увеличенные фрагменты, шпаргалку признаков регионов России и соседних стран (`geobot/data/meta_ru.md` плюс таблицы трасс и брендов) и всё найденное, а возвращает наблюдения и **5 кандидатов с вероятностями**;
   - если вы уже отметили через `/ответ` хотя бы 3 фото, Gemini получает подсказку «раньше ваши фото оказывались в …» (отключается `HISTORY_HINT=0`);
   - поиск Google внутри Gemini можно включить (`GEMINI_SEARCH=1`), но на бесплатном тарифе для моделей Gemini 3 он недоступен, поэтому по умолчанию выключен;
   - когда у модели кончается дневной лимит, бот переходит к следующей (3.8 → 3.7 → 3.6 → 3 Flash Preview, у каждой около 20 запросов в день).
9. **Замер точности.** Знаете правильное место — ответьте на сообщение бота `/ответ город, улица` (или `/answer`, координаты, геопозиция). Бот посчитает ошибку в километрах, а `/stats` покажет медианную ошибку и доли попаданий «до 1 / 25 / 200 / 750 км».
10. **Кнопка «Текст для ИИ-чата»** собирает всё найденное в текст. Его можно вставить вместе с фото в приложение Gemini, ChatGPT или Claude.

Бот работает без ИИ и без платных сервисов. Памяти ему нужно около 80 МБ, поэтому хватает бесплатного тарифа Bot-Hosting.net (256 МБ). Тяжёлые библиотеки вроде aiogram здесь не используются: с Telegram бот общается напрямую через Bot API.

## Что понадобится

| Что | Где взять | Обязательно? |
|---|---|---|
| Токен бота | Telegram → [@BotFather](https://t.me/BotFather) → `/newbot` | да |
| Ключ OCR.space | [ocr.space/ocrapi](https://ocr.space/ocrapi), бесплатный ключ приходит на почту | желательно, без него текст на фото не читается |
| Ключ Gemini API | [aistudio.google.com](https://aistudio.google.com) → *Get API key* | нет |

Ключи и токен **никому не пересылайте**: ни в чат, ни в код, ни на GitHub. Они вписываются только в файл `.env` на сервере.

## Настройка

1. Скопируйте `.env.example` в `.env`.
2. Впишите `BOT_TOKEN` и `OCR_SPACE_KEY`. По желанию впишите `GEMINI_API_KEY`.
3. Запустите бота и напишите ему `/id`. Он ответит вашим Telegram ID.
4. Впишите этот ID в `ALLOWED_USERS` (несколько ID — через запятую) и перезапустите бота.

Пока `ALLOWED_USERS` пустой, бот никого не обслуживает, только сообщает ID. Это защита: в чужих руках определение места по фото может использоваться для слежки.

## Бот для всех

1. В `ALLOWED_USERS` впишите `*`.
2. В `ADMIN_USERS` впишите свой ID (несколько — через запятую).
3. Перезапустите бота.

Как работает открытый режим:

- **Лимит.** Каждый может прислать `DAILY_LIMIT` фото в день (по умолчанию 5). Счётчик обнуляется в полночь по Москве. Неудачный анализ в лимит не засчитывается. На администраторов лимит не действует.
- **Очередь.** Фото обрабатываются по одному, чтобы бот уложился в 256 МБ памяти. Если бот занят, человек видит «перед вами N фото», а когда подходит его очередь, сообщение само сменится на результат. Когда в очереди больше `QUEUE_LIMIT` фото, новые бот просит прислать позже.
- **`/admin`** показывает:
  - сколько людей и фото было сегодня, за неделю и всего;
  - кто сколько фото прислал сегодня (ID и ник);
  - кто забанен;
  - общую точность бота;
  - последнюю ошибку Gemini.
- **`/ban ID`** закрывает человеку доступ, **`/unban ID`** возвращает. ID можно посмотреть в `/admin`.
- **`/stats`** у каждого свой: точность считается только по его ответам `/ответ`. Подсказка Gemini «раньше ваши фото оказывались в …» тоже строится по истории этого человека.

Бесплатных запросов Gemini хватает примерно на 80 фото в день на всех. Когда они кончаются, бот продолжает работать без Gemini, но ответы становятся заметно грубее. Если пользователей много, уменьшите `DAILY_LIMIT`.

Фото пользователей уходят в Яндекс, OCR.space и Google (Gemini), поэтому ответ за то, кто и что присылает боту, лежит на вас.

## Запуск на Bot-Hosting.net

Интерфейс панели может отличаться. Общий порядок такой:

1. Зарегистрируйтесь на [bot-hosting.net](https://bot-hosting.net) и создайте бесплатный сервер с **Python**.
2. Откройте файловый менеджер сервера и загрузите туда **содержимое папки `geobot/`**:
   - файлы `main.py`, `requirements.txt` и `.env`;
   - папку `geobot/` с кодом.
3. В настройках запуска (*Startup*) укажите главный файл `main.py` и файл зависимостей `requirements.txt`.
4. Нажмите **Start** и посмотрите консоль. Должна появиться строка `bot started`.
5. **Каждые 4 дня продлевайте сервер в панели**, иначе бесплатный сервер остановится.

Если при установке ругается на `pillow-heif`, удалите эту строку из `requirements.txt`. Бот будет работать, только без поддержки HEIC-файлов с iPhone. Обычные фото и JPG будут обрабатываться как раньше.

## Запуск на своём компьютере

```bash
cd geobot
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

Нужен Python 3.10 или новее.

## Gemini

- Модели задаются переменными `GEMINI_MODELS` (итоговый анализ, по порядку) и `GEMINI_LITE_MODELS` (поиск деталей). Старая переменная `GEMINI_MODEL` тоже работает: её модель идёт первой. Актуальные лимиты видны в Google AI Studio → Rate limits.
- На каждое фото уходит 1 запрос к Lite-модели и 1 к Flash: при бесплатных лимитах это около 80 фото в день.
- Подписка Gemini Pro к API не относится: у API свой бесплатный лимит.
- Ключ должен принадлежать вам. Пользуясь им, вы соглашаетесь с [условиями Gemini API](https://ai.google.dev/gemini-api/terms).
- Фото отправляется в Google, поэтому не присылайте боту снимки, которые не хотели бы показывать посторонним.

## Ограничения

- **Обычные фото Telegram сжимает и удаляет из них GPS.** Для точности отправляйте файлом: 📎 → Файл.
- **Без надписей и узнаваемых объектов** без Gemini бот даст только кнопки поиска и общие подсказки.
- **Справочник телефонных кодов городов** охватывает только крупные города России. Если кода нет в справочнике, это не значит, что номер не российский.
- **Бесплатные сервисы** (OCR.space, OpenStreetMap, Wikimedia, Litterbox) могут ограничивать частоту запросов. Тогда бот просто пропустит соответствующий шаг.

## Устройство

```
main.py              запуск
geobot/bot.py        приём сообщений и ответы
geobot/telegram.py   минимальный клиент Telegram Bot API
geobot/analyze.py    порядок проверок и выбор лучшей точки
geobot/exif.py       метаданные: GPS, направление, время
geobot/textclues.py  алфавиты, телефоны, номера машин, домены
geobot/services.py   поиск по картинке в Яндексе, OCR.space, Litterbox, OpenStreetMap, Wikimedia Commons
geobot/gemini.py     Gemini: поиск деталей, итоговый анализ, переключение моделей, поиск Google
geobot/imaging.py    вырезание увеличенных фрагментов из оригинала
geobot/history.py    история ответов и статистика точности (/ответ, /stats)
geobot/users.py      лимиты, баны и счётчики пользователей (/admin, /ban)
geobot/data/meta_ru.md  шпаргалка признаков регионов для Gemini
geobot/knowledge.py  трассы, бренды, названия населённых пунктов → регионы
geobot/gazetteer.py  офлайн-справочник населённых пунктов (SQLite)
geobot/data/ru_roads.py, ru_brands.py, ru_regions.py  таблицы
tools/build_gazetteer.py  сборка базы населённых пунктов из GeoNames
geobot/report.py     текст ответа и «досье» для ИИ-чата
geobot/data/         справочники
```

Тесты: `pip install pytest && python -m pytest tests`.

База населённых пунктов `geobot/data/ru_places.sqlite` собрана из [GeoNames](https://www.geonames.org/) (CC BY 4.0). Она лежит в архиве для загрузки; если её нет (например, код взят с GitHub), бот сам скачает данные и соберёт базу при первом запуске — это занимает около минуты. Пересобрать вручную: `python tools/build_gazetteer.py`.

Таблица телефонных кодов стран взята из проекта [geo-sleuth](https://github.com/Oldcircle/geo-sleuth) (MIT License, © 2026 Oldcircle), данные — Wikipedia.
